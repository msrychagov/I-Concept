# Диаграммы результатов

Диаграммы доступны преподавателю в трёх блоках и в карточках, открытых через
путь «взвод → студент». Отображаются существующие поля отчётов и готовой разметки.
Расчёт результатов, ключи методик и шкала потенциала остаются на сервере.

| Где открыть | Что показано |
| --- | --- |
| Автобиография → анкета → «Вывод» → «Потенциал» | Направления с опытом и их категории по действующей шкале потенциала. Категории показаны отдельными ячейками. |
| Автобиография → «Потенциал по взводу» | Число студентов каждого уровня по шести направлениям. Сегмент открывает список студентов, имя — анкету. |
| Тестирование → результат студента → «Диаграммы» | Я-реальное и Я-идеальное по группам качеств на шкале 0–10; баллы каждой методики в её собственном диапазоне; ответы о климате на шкале −3…+3. |
| Тестирование → результат → «Диаграмма показателей по утверждениям» | Средние баллы показателей на шкале 1–5. Доступно также для тестирований без блока методик. |
| Тестирование → «Уровни методик по взводу» | Распределение по готовым уровням. Сегмент открывает ту же группу студентов, что и число в таблице. В подробностях выбранного взвода — средние оценки климата. |
| Эссе → сданное эссе → «Ценности в эссе» | Число упоминаний по идеям Онтографа. Отдельные цвета для принятия, отвержения и тех же проявлений в повседневной жизни. Появляется с готовой разметкой. |
| Эссе → «Сводка по выпуску» | Готовность эссе и разборов; при готовой разметке — число авторов, принимающих ценности каждой идеи. |

В распределениях длина сегмента пропорциональна числу студентов, знаменатель
одинаков для всех строк. Авторы в графике ценностей считаются из текстов с готовой
разметкой; один автор может входить в несколько строк. Упоминания в одном тексте
и авторы выпуска используют разные единицы счёта. Таблицы и цитаты остаются рядом
с диаграммами.

Пропуск отображается как «Нет данных» с пунктирной дорожкой. Нулевой ответ
отображается числом 0 и отметкой у начала шкалы (для климата — в её центре).
Графики сохраняют собственные диапазоны методик. Суммарного балла по человеку
и процентов «развития личности» диаграммы не рассчитывают.

Реализация — `web/static/js/teacher/charts.js` и `web/static/css/charts.css`.
Внешних библиотек и дополнительных запросов для построения диаграмм нет.
На узком экране подпись размещается над столбцом; числовые подписи и текстовые
расшифровки доступны независимо от цвета. Сегменты сводок — обычные кнопки с
описанием и обозначением выбранной группы, доступны с клавиатуры.

Проверки без внешних зависимостей:

```bash
node --test scripts/charts.test.cjs
```

Восемь проверок охватывают пропуски и нули, отрицательные оценки климата,
разные диапазоны методик, категориальный потенциал, параметры выбора группы,
знаменатель готовой разметки, экранирование HTML и статусы обработки эссе.
