# ИИ-отчёты: ответы локальной модели

Фактические данные, баллы, охват и структура отчёта рассчитываются сервером. Интерпретации доступных показателей, общий вывод и рекомендации формирует Qwen через Ollama. Отчёт публикуется только после проверки всех запрошенных блоков. Шаблонной подмены и частично сгенерированных отчётов нет.

При ошибке, пустом ответе, неверном JSON или непрохождении проверки API возвращает `failed` без отчёта. Интерфейс показывает «Не удалось сформировать отчёт. Попробуйте позже» и кнопку «Попробовать ещё раз». Она отправляет POST и запускает новую генерацию с первого блока. POST не возвращает готовый или ошибочный кэш; уже выполняющийся запрос не дублируется. GET используется для опроса состояния. HTTP-кэш отключён.

Числовые результаты и ограничения сохраняются. Показатели без расчёта не интерпретируются моделью. P01–P03 не используются для оценки личности. Для взвода сохраняется порог минимум трёх участников на показатель. При отсутствии пригодных данных ИИ-отчёт не формируется.

Проверки: `go test ./...`, `go test -race ./internal/usecase -run 'TestAI|TestChapter'`, `node --test web/tests/ai-reports.test.cjs`.
