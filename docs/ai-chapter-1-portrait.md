# Психолого-педагогический портрет по главе 1 — редакция 4

## Цель правки

Основной вывод должен быть **портретом по результатам тестирования**, а не набором фраз «Темы для беседы», «Вывод требует наблюдения» и пояснений об ограниченности самоотчёта. Модель не обязана перечислять максимальные/минимальные баллы; она описывает заявленные студентом установки, особенности самооценки и восприятия учебной среды на основании конкретных ответов.

## Механизм

- Go вычисляет результаты по прежней методике, без участия модели.
- В `internal/usecase/ai_chapter_portrait.go` хранится сжатая теоретическая основа из главы 1 и инструктаж на профессиональный, предметный русский язык.
- Qwen получает данные небольшими группами, формирует пояснения к показателям и отдельно пишет **четыре связных абзаца** общего портрета: ценностно-смысловые установки; эмоционально-волевая саморегуляция; учебное взаимодействие и действия; восприятие среды ВУЦ, актуальный и желаемый образы себя.
- Параграфы должны утверждать только то, что следует **из самого самоописания**. Нельзя выдумывать наблюдаемое поведение, медицинские диагнозы, пригодность к службе либо оценивать политические убеждения как личностные черты.
- Повторяющиеся методические оговорки и «темы для беседы» запрещены в системном и пользовательском промптах и отбраковываются валидатором.
- Нормальная оговорка о пределах методики осталась **только в отдельном поле `limitations`**, а не в общем выводе.
- При ошибке или слабом ответе модели показывается сообщение об ошибке и кнопка повторного запроса. Отсутствующие сведения никогда не заменяются выдуманными характеристиками.
- Поля JSON и интерфейс отчёта не менялись. Для отчётов взвода также отключена шаблонная подмена. Задания, расчёты, база данных и остальные страницы сохранены.

## Установка

Из архива «Только изменения» скопировать файлы в корень существующего проекта с сохранением относительных путей. Пересобрать приложение:

```sh
docker compose -f docker-compose.yaml -f docker-compose.cpu-ai.yml --profile ai up -d --build app
```

Модель Qwen3 1.7B повторно загружать не нужно. После пересборки временный кэш очищается. Повторный POST создаёт отчёт заново; выполняющийся запрос не дублируется.

## Проверка

Проект и тесты требуют Go 1.26. Команды проверок приведены в ai-report-v2.md. Результат на реальной Qwen 1.7B зависит от скорости CPU и способности модели ответить в JSON; *никакой промпт не обеспечивает 100% достоверности психологического портрета*. Для проверки качества использовать обезличенные результаты разных студентов и экспертную оценку психолога.
